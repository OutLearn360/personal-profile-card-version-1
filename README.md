# Personal Profile Card — Version 1

A simple and responsive **Personal Profile Card** built using **HTML and CSS**.

This project is part of my **Web Development Projects** YouTube series, where I build practical projects step by step while learning and demonstrating HTML, CSS, and JavaScript.

<img align="right" alt="GIF" src="https://github.com/OutLearn360/personal-profile-card-version-1/blob/a426b364aeb398daf4819c0280c5a0917ffc1c15/Personal%20Profile%20Card.png"/>
  

## 🚀 Project Preview

This project creates a clean profile card containing:

* Profile avatar
* Name and job title
* Location
* Short biography
* Project, experience, and client statistics
* Skills
* Contact button
* GitHub profile button

The card is centered on the page and includes responsive behavior for smaller screens.

## 🛠️ Technologies Used

* HTML5
* CSS3

No JavaScript or external frameworks are used in this version.

## ✨ Features

### Profile Card

The main profile card contains a banner, circular avatar, profile information, biography, statistics, skills, and action links.

### Profile Statistics

The card displays:

* **24** Projects
* **3+** Years
* **18** Clients

### Skills

The project includes skill tags for:

* HTML
* CSS
* Responsive Design

### Responsive Design

The layout adapts to smaller screens. On screens up to 420px wide, the action buttons change from a horizontal layout to a vertical layout.

### Interactive Links

The card includes:

* **Contact Me** — opens an email link
* **GitHub Profile** — opens a GitHub profile in a new browser tab

## 🎨 CSS Concepts Demonstrated

This project demonstrates several useful CSS concepts, including:

* Flexbox
* Responsive design
* `border-radius`
* `box-shadow`
* Padding and margins
* Typography
* CSS colors
* Flex wrapping
* Hover and focus states
* Media queries

For example, Flexbox is used to center the profile card and organize elements such as the statistics and skill list.
